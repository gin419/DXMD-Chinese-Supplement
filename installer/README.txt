Deus Ex: Mankind Divided - Chinese Localization Installer

INSTALL
1. Extract this complete folder to any local drive.
2. Double-click Install-DXMD-Chinese.cmd.
3. Approve the Windows UAC prompt.
4. The installer finds the Steam game automatically. If it cannot, enter the full path ending in retail.

This package includes the Windows 11-compatible DXMD-Translations framework DLL, the revised Chinese strings, the Chinese UI font, and the required configuration.

REQUIREMENTS
- Steam Deus Ex: Mankind Divided, preferably DXMD.exe version 1.19.
- Latest Microsoft Visual C++ x64 Redistributable. If the game does not start, install it from Microsoft:
  https://aka.ms/vs/17/release/vc_redist.x64.exe

UNINSTALL
Double-click Uninstall-DXMD-Chinese.cmd. The installer keeps a backup inside the game retail folder and restores the newest backup.

NOTES
- Do not mix this package with the Turkish strings.json or font_ui_tr.swf.
- The translation data is a revised test translation. Some UI text may still need manual adjustment.
- The package does not modify DXMD.exe or game archives.
